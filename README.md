# Project-Chronos-The-AI-archeologist

 Project Chronos uses Google Gemini’s AI to reconstruct incomplete historical texts by predicting missing words or phrases based on linguistic context and style. It generates a detailed report with the restored text and sources, aiding archaeologists and historians in recovering lost knowledge.

## 🚀 Quick start 

### Prerequisites
 - Google Gemini: Get from [AI Studio](https://aistudio.google.com/app/apikey).



## Installation 
 - Clone or create the project folder.
 - Copy API key into `.env` (format: `GEMINI_API_KEY=your_key` ).
 - Install dependencies: `pip install -r requirements.txt`.
